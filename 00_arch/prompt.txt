           13. Promote temp file to final output (.par)
           14. Write validation log entry
           15. Commit Kafka offsets
           16. Exit: Success (stable count confirmed)
         → No:
           17. [Decision] Retry window exhausted?

                 18. Promote temp file to final output (.par)
                 19. Write validation log entry
                 20. Commit Kafka offsets
                 21. Exit: Success (accepted — stability unconfirmed, window expired)
               → No:
                 22. Delete temporary file
                 23. Sleep (retry interval)
                 → loop back to "Begin collection attempt"

     NO branch (under expected):

           → loop back to "Begin collection attempt"

                 29. Promote temp file to final output (.par)
                 30. Write validation log entry (warning: below expected but within tolerance)
                 31. Commit Kafka offsets
                 32. Exit: Success with Warning (below expected, within tolerance)
               → No:
                 33. Delete temporary file
                 34. Log failure analysis (which filter values were found vs expected)
